# V4-05A — Clôture d'équipe : bilan et événement persistants

Branche `work/v2-phase1-engine`, PR #1. Reprise vérifiée sur `f2c5780` ; code `7dff62138f5bb77a6bd48e342ff65b236748e45c`.

## Exigences couvertes

Cette tranche prépare le §8.7 V4 côté serveur, avant le stationnement et le message de félicitations.

- Un événement `closure` est ajouté à la transaction de dernière semaine active éligible résolue. Toutes les semaines actives de l'équipe doivent avoir un résultat ; un report ouvert ne disparaît pas parce qu'une date du calendrier est passée.
- Son identifiant est stable par entreprise/campagne/équipe. Le bilan garde la distance exacte, le maximum des seules semaines actives et les seuils des seuls droits cadeaux attribués.
- Aucun kilomètre n'est ajouté pour rejoindre le terminus. Aucun cadeau non acquis n'est attribué, et aucune tâche cadeau supplémentaire n'est créée par la clôture.
- Le bilan est conservé dans le journal existant, avec les résultats et cadeaux. Sa projection publique exclut les identifiants internes d'équipe/entreprise, les coûts et les secrets logistiques.
- Le mécanisme existant de présentation permet de réclamer l'événement une seule fois par collaborateur. Le bilan reste lisible ensuite. Cela garantit au plus une présentation automatique, pas la preuve que l'utilisateur a effectivement vu l'animation en cas de coupure réseau.
- Une semaine de pause collective après la dernière semaine active ne crée pas une seconde clôture et ne modifie pas le bilan.

L'interface actuelle ne consomme pas encore la clôture : aucun écran de félicitations, animation, replay de fin, parking ou nouvelle capture n'est annoncé. Aucun nouveau déploiement Firebase pour cette tranche ; le serveur de test reste sur V4-04.

La fin déclenchée par date seule avec des semaines encore non résolues n'est pas implémentée. Une politique explicite devra résoudre ces semaines (reports/non-réponses) sans effacer les droits. Les campagnes déjà entièrement terminées avant cette version ne sont pas rétroactivement clôturées ; aucune migration n'est exécutée.
